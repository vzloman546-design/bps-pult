# Публикация БПС Пульт 2.6.0 на GitHub Pages

## Перед загрузкой

1. Откройте адрес Worker:
   `https://bps-pult-push.vzloman546.workers.dev/health`
2. Ответ должен быть `ok`.
3. В Cloudflare должны быть добавлены D1 binding `DB`, переменные `VAPID_PUBLIC_KEY`, `VAPID_SUBJECT`, `ALLOWED_ORIGIN` и секреты `VAPID_PRIVATE_KEY`, `PAIRING_CODE`.
4. `ALLOWED_ORIGIN` должен быть строго `https://vzloman546-design.github.io`.

## Загрузка

Загрузите **содержимое этой папки** в корень репозитория `bps-pult`, заменив старые файлы. Главный `index.html` должен находиться в корне репозитория, а не во вложенной папке.

Рекомендуемое сообщение коммита:

```text
Release БПС Пульт 2.6.0 — Web Push уведомления
```

## После публикации

1. Дождитесь завершения GitHub Pages.
2. Откройте установленный «БПС Пульт» с экрана «Домой».
3. Подтвердите обновление до версии 2.6.0.
4. Перейдите `Ещё → Настройки → Уведомления`.
5. Нажмите «Включить уведомления».
6. Введите свой `PAIRING_CODE` из Cloudflare.
7. Разрешите уведомления в системном окне iOS.
8. Нажмите «Отправить тестовое».

Секреты Cloudflare в этот архив не включены.
