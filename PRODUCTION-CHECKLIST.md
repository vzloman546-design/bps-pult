# Production checklist — БПС Пульт 2.0.0

## Автоматически проверено

- [x] синтаксис JavaScript;
- [x] 9 сценариев конфигурации мероприятий;
- [x] 10 сценариев базы знаний;
- [x] 8 групп сценариев миграции, backup, ZIP и целостности;
- [x] повреждённый архив отклоняется;
- [x] неудачная атомарная замена сохраняет старую запись;
- [x] удаление и отмена восстанавливают объект;
- [x] удаление мероприятия не оставляет потерянные ссылки;
- [x] service worker не активирует обновление автоматически;
- [x] нет горизонтального overflow на 320/375/390/430 px;
- [x] нижняя панель остаётся fixed после прокрутки;
- [x] формы не имеют внутреннего горизонтального overflow;
- [x] фон модального окна получает `inert`;
- [x] фокус находится внутри диалога и возвращается после закрытия;
- [x] нет необозначенных интерактивных элементов в основных разделах;
- [x] нет runtime-ошибок в браузерном UI-аудите.
