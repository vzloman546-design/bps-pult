# Production checklist — БПС Пульт 2.7.0

> Автоматические пункты и браузерный baseline ниже перенесены из предыдущих приёмок; обязательная повторная проверка 2.7.0 на реальном iPhone остаётся отдельным незакрытым блоком.

## Автоматически проверено

- [x] синтаксис JavaScript;
- [x] 11 сценариев конфигурации мероприятий;
- [x] 17 сценариев базы знаний, включая прикрепление документов;
- [x] 16 групп сценариев миграции, backup, ZIP, undo и целостности, включая документы;
- [x] 18 статических контрактов транзакций, черновиков и переходов UI;
- [x] 2 динамических сценария отмены ожидающего автосохранения;
- [x] 4 группы сценариев глобального поиска, дубликатов, отчётов и связей;
- [x] повреждённый архив отклоняется;
- [x] неудачная атомарная замена сохраняет старую запись;
- [x] удаление и отмена восстанавливают объект;
- [x] удаление мероприятия не оставляет потерянные ссылки;
- [x] service worker не активирует обновление автоматически;
- [x] активный service worker не читает waiting-кэш;
- [x] 12 разделов в обеих темах не имеют горизонтального overflow на 320/375/390/430 px;
- [x] нижняя панель остаётся fixed после прокрутки;
- [x] формы не имеют внутреннего горизонтального overflow;
- [x] фон модального окна получает `inert`;
- [x] фокус находится внутри диалога и возвращается после закрытия;
- [x] нет необозначенных интерактивных элементов в основных разделах;
- [x] нет runtime-ошибок приложения в браузерном UI-аудите;
- [x] тестовые копии схем 4 и 5 проходят миграцию в схему 6 с сохранением новых полей и документов;
- [x] запуск оболочки и локальных данных проверен при остановленном HTTP-сервере;
- [x] светлая, тёмная и повышенно-контрастная геометрия проверена в браузере.

## Обязательная приёмка на реальном iPhone

- [ ] установить PWA заново с GitHub Pages;
- [ ] разрешить постоянное хранение, если iOS предложит;
- [ ] создать мероприятие, статью, запись, задачу и осмотр;
- [ ] прикрепить фотографии с камеры;
- [ ] импортировать реальную HEIC-фотографию с камеры и проверить сжатый результат;
- [ ] заполнить форму, принудительно закрыть PWA и проверить восстановление черновика;
- [ ] закрыть приложение принудительно и проверить данные;
- [ ] перезагрузить iPhone и открыть без сети;
- [ ] создать `.bpsbackup` и сохранить его в «Файлы»;
- [ ] восстановить архив на чистой тестовой установке;
- [ ] обновить установленную версию 2.5.1 до 2.7.0 без очистки данных;
- [ ] проверить предупреждение об открытом черновике и напоминание о backup перед обновлением;
- [ ] проверить светлую/тёмную системную строку и safe-area;
- [ ] пройти основные формы с VoiceOver;
- [ ] проверить ввод при увеличенном системном размере текста.

До выполнения блока приёмки не следует хранить в приложении единственную копию критически важных данных.
