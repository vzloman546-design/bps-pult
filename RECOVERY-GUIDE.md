# Восстановление БПС Пульта

## Приложение не открывается

1. Не удаляйте иконку PWA.
2. Не очищайте историю и данные Safari.
3. На аварийном экране нажмите «Повторить запуск».
4. Если ошибка повторяется, скачайте диагностический отчёт.
5. Полностью закройте приложение и перезагрузите iPhone.

## Восстановление из архива

1. Откройте `Ещё → Настройки и данные`.
2. Нажмите «Восстановить».
3. Выберите `.bpsbackup` или старую JSON-копию.
4. Проверьте количество объектов и предупреждения.
5. Выберите:
   - **Заменить** — текущая база заменяется атомарно;
   - **Объединить** — записи объединяются по идентификаторам.
6. Дождитесь сообщения об успешном восстановлении.
7. Запустите «Проверить целостность базы».

Если архив повреждён, приложение не очищает текущую базу.

## Проверка чистого восстановления

Для контрольного теста:

1. Создайте резервную копию.
2. Сохраните её в «Файлы» или iCloud Drive.
3. На отдельной тестовой установке импортируйте архив.
4. Сравните количество мероприятий, статей, записей, задач, осмотров и оборудования.
