# БПС Пульт 2.6.0 — отчёт интеграции Web Push

## Подключено

- Cloudflare Worker: `https://bps-pult-push.vzloman546.workers.dev`;
- Push API и Notifications API;
- VAPID-подписка через публичный ключ Worker;
- настройки уведомлений внутри PWA;
- задачи, мероприятия, открытие входов и резервные копии;
- локальная очередь при отсутствии сети;
- переход из уведомления в нужный раздел;
- управляемое обновление Service Worker сохранено.

## Безопасность

В проекте отсутствуют `VAPID_PRIVATE_KEY`, `PAIRING_CODE` и данные push-подписки. Они находятся только в Cloudflare или локальном хранилище установленной PWA.

## Обязательная проверка на iPhone

1. Опубликовать содержимое папки в GitHub Pages.
2. Открыть PWA с экрана «Домой».
3. В разделе «Настройки → Уведомления» подключить устройство.
4. Отправить тестовое уведомление.
5. Создать задачу со сроком через несколько минут, закрыть PWA и проверить получение.
6. Проверить открытие нужной задачи после нажатия на уведомление.
