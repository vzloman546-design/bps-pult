# UI-аудит БПС Пульт v2.0.0 Alpha 3

Дата: 31.07.2026.

## Единая сетка

Приложение использует 4/8-point grid без отдельных размеров для модуля базы знаний:

- боковые поля страницы — 20 px;
- основной шаг — 8 px;
- gap внутри строк — 12 px;
- внутренний padding карточек — 16 px;
- расстояние между секциями — 32 px;
- поля и основные кнопки — не менее 48 px;
- touch target — не менее 44 px;
- строки списков — не менее 72 px;
- радиус control — 10 px;
- радиус карточки — 14 px;
- радиус bottom sheet — 20 px.

## Фактические измерения базы знаний

Viewport 390 px:

- левая направляющая lead/search/status/categories — 20 px;
- правая направляющая — 370 px;
- ширина страницы — 390 px;
- ширина документа — 390 px;
- высота поиска — 49 px;
- высота сводки — 78 px;
- минимальная высота строки раздела — 72 px;
- нижняя панель заканчивается ровно на границе viewport: 844/844 px.

Viewport 320 px:

- ширина документа — 320 px;
- горизонтальный overflow отсутствует;
- overflow редактора — 0 px.

## Исправления в модуле базы знаний

- главный экран, поиск, сводка и списки выровнены по одной направляющей;
- кнопки «Новый материал» и «Разделы» имеют равную ширину;
- горизонтальные фильтры прокручиваются внутри своей области и не расширяют страницу;
- редактор всегда одноколоночный на iPhone;
- между полями редактора установлен gap 16 px;
- устранено наложение label следующего поля на select предыдущего;
- длинные заголовки, пути разделов и текст используют безопасный перенос;
- нумерация шагов имеет фиксированную колонку 32 px;
- связанные объекты представлены строками высотой 64 px;
- действия карточки идут одной колонкой на iPhone;
- bottom sheet использует существующее закрытие свайпом вниз;
- строки материалов поддерживают существующие swipe-actions.

Подробные числовые результаты: `GRID-AUDIT-METRICS.json`.
