# Аудит интерфейса БПС Пульт v1.3.0

## Обнаруженные проблемы предыдущей версии

1. **Не было единой сетки.** Одновременно использовались отступы 9, 10, 11, 13, 14, 15, 18, 22 и 25 px. Из-за этого заголовки, карточки и элементы форм визуально не совпадали.
2. **Разные горизонтальные направляющие.** Шапка использовала 18 px, основной контент — 16 px, отдельные заголовки дополнительно смещались на 2–4 px.
3. **CSS накапливался слоями.** Компоненты несколько раз переопределялись в конце файла, поэтому итоговый размер зависел от порядка правил.
4. **Непоследовательные скругления.** В одном экране встречались радиусы 8, 10, 13, 16 px и унаследованные значения из ранних версий.
5. **Слишком маленькие интерактивные области.** Текстовые кнопки, переключатели сегментов и чек задачи местами были ниже 44 px.
6. **Перегруженные строки.** В журнале статус и время находились в правой колонке, из-за чего длинные статусы нарушали баланс строки.
7. **Формы были неодинаковыми.** Часть полей использовала двухколоночную сетку на узком iPhone, часть — один столбец; внутренние карточки имели ручные inline-отступы.
8. **Страница осмотров выглядела как рекламный экран.** Большая hero-карточка не соответствовала рабочему назначению приложения.
9. **Автофокус bottom sheet попадал на «Отмена».** На некоторых браузерах это создавало лишнюю рамку фокуса, а автоматический фокус поля на iPhone мог неожиданно открыть клавиатуру.

## Принятая сетка

Базовый модуль — **4 px**, основной шаг — **8 px**.

| Назначение | Значение |
|---|---:|
| Минимальный микрозазор | 4 px |
| Зазор между связанными элементами | 8 px |
| Зазор внутри строки | 12 px |
| Стандартный внутренний отступ карточки | 16 px |
| Боковой отступ страницы | 20 px |
| Отступ между крупными блоками | 24–32 px |
| Минимальная зона касания | 44×44 px |
| Высота полей и основных кнопок | 48 px |
| Высота строки списка | не менее 72 px |
| Радиус полей | 10 px |
| Радиус карточек | 14 px |
| Радиус bottom sheet | 20 px |

## Выполненные исправления

- Полностью переписан `styles.css`; старые конфликтующие правила удалены.
- Введены токены `--space-*`, `--content-gutter`, `--control-height`, `--tap-size`, `--radius-*`.
- Шапка и основной контент используют одну вертикальную направляющую в 20 px.
- Все секции используют одинаковую структуру: заголовок высотой 44 px → зазор 12 px → содержимое → отступ 32 px.
- Показатели на главной объединены в четыре равные колонки.
- Все строки списков имеют одинаковые высоту, padding, размер иконки и положение текста.
- Время записи перенесено в метаданные строки; справа остаётся только статус.
- Чек задачи получил визуальный круг 28 px внутри полноценной зоны касания 44 px.
- Формы в bottom sheet на телефоне идут в один столбец; на широком экране переходят в два.
- Фильтры журнала размещены в ровной сетке 2×2.
- Удалены ручные inline-отступы у карточек, переключателей и кнопочных групп.
- Hero-блок техосмотров заменён компактным рабочим описанием и одной основной кнопкой.
- На мобильном устройстве bottom sheet больше не автофокусирует поле и не вызывает клавиатуру самопроизвольно.
- Нижняя навигация остаётся фиксированной при любой длине страницы.
- Добавлена поддержка `prefers-reduced-motion`.

## Проверки

Проверены mobile viewport 390×844 px и светлая/тёмная темы:

- горизонтальный overflow отсутствует на всех основных разделах;
- минимальная интерактивная высота — 44 px;
- нижняя навигация остаётся на координате нижнего края после прокрутки;
- свайп вниз закрывает bottom sheet;
- свайп влево открывает действия строки;
- JavaScript и service worker проходят синтаксическую проверку;
- манифест является валидным JSON.
