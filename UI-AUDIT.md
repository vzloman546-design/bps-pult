# UI-аудит БПС Пульт 2.5.0

## Сетка

Используется 4-px базовый модуль и основной шаг 8 px.

| Назначение | Значение |
|---|---:|
| малый интервал | 4 px |
| стандартный интервал | 8 px |
| расстояние элементов строки | 12 px |
| внутренний отступ карточки | 16 px |
| боковой отступ страницы | 20 px |
| расстояние крупных секций | 32 px |
| минимальная зона касания | 44×44 px |
| высота основного контрола | 48 px |
| радиус поля | 10 px |
| радиус карточки | 14 px |
| радиус bottom sheet | 20 px |

## Проверки

- контент, шапка и карточки используют общую направляющую;
- списки имеют одинаковую высоту и внутренние отступы;
- поля мобильных форм расположены в одну колонку;
- длинные подписи переносятся без наложения на переключатели;
- кнопки действий не выходят за viewport;
- fixed-навигация находится вне трансформируемой оболочки;
- нижний safe-area учитывается;
- модальные окна не прокручивают фон;
- свайп вниз сохранён;
- светлая и тёмная темы используют одинаковую геометрию;
- update banner располагается над нижней навигацией;
- toast с действием «Отменить» не перекрывает Home Indicator.

## Итоговый прогон 31.07.2026

- 12 разделов проверены на 320, 375, 390 и 430 px в светлой и тёмной темах: 96 маршрутных проверок;
- в аудит включены новые разделы глобального поиска и отчётов;
- формы записи, задачи, осмотра, оборудования, мероприятия и статьи проверены на 320 px;
- сложные формы мероприятия и базы знаний проверены на всех четырёх ширинах в обеих темах;
- конфигуратор дополнительно проверен с раскрытыми гейтом, восемью турникетами, кассой и сменой кассира;
- карточка мероприятия проверена с 32 пунктами чек-листа;
- у страниц и bottom sheet отсутствует внутренний горизонтальный overflow;
- `position: fixed` и нижняя граница `0` подтверждены для нижней навигации;
- фон диалога получает `inert`/`aria-hidden`, Escape закрывает окно, фокус возвращается и сохраняется после перерисовки;
- доступные имена отсутствующих ранее controls подтверждены через accessibility snapshot;
- видимые нативные checkbox имеют размер 22×22 px внутри кликабельной строки-label высотой 64 px; эффективная зона касания превышает 44×44 px;
- блок «Связано с» не содержит скрытых свайп-действий редактирования или удаления;
- повышенный контраст сохраняет ту же геометрию и зоны касания;
- минимальный контраст основного текста действий: 4.66:1 в светлой теме и 7.03:1 в тёмной.
