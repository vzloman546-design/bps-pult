# БПС Пульт 2.5.1

Локальная mobile-first PWA для инженера билетно-пропускной системы. Приложение работает без серверной базы: рабочие данные хранятся в IndexedDB установленной PWA на конкретном iPhone.

## Основные модули

- гибкие мероприятия: СИБ, гейты, отдельные турникеты, кассы и смены кассиров;
- автоматически генерируемый чек-лист готовности;
- журнал событий и выполненных работ;
- задачи, сроки и приоритеты;
- технические осмотры;
- реестр оборудования;
- структурированная база знаний с разделами, поиском, историей версий и актуальностью;
- сводки и отчёты за выбранный период с CSV, печатью и копированием;
- глобальный поиск и переходы между связанными объектами;
- офлайн-работа и установка на экран «Домой».

## Что делает версию Stable

- все операции IndexedDB подтверждаются только после завершения транзакции;
- связанные запись/осмотр и задача создаются одной транзакцией;
- merge и живая миграция читают и записывают данные внутри одной транзакции;
- восстановление резервной копии выполняется одной атомарной транзакцией;
- повреждённый архив не очищает текущую базу;
- поддерживаются миграции схем 1, 2, 3 и 4 в схему 5;
- новый архив `.bpsbackup` является ZIP-контейнером с `manifest.json`, `data.json` и отдельными фотографиями;
- доступен режим «Заменить» и безопасное объединение;
- проверяются идентификаторы, даты и связи между объектами;
- удаления помещаются в локальную корзину на 7 дней и допускают немедленную отмену;
- при удалении мероприятия или оборудования связанные ссылки очищаются атомарно и восстанавливаются при отмене;
- отмена удаления не затирает параллельные правки связанных объектов;
- добавлены контроль квоты и запрос постоянного хранения;
- обновление service worker применяется только после явного нажатия «Обновить»;
- активный service worker читает только собственный версионный кэш и не смешивает файлы с waiting-версией;
- HTML запрашивает JS/CSS по URL версии 2.5.1 для согласованного перехода между worker;
- модальные окна блокируют фон, удерживают фокус и возвращают его после закрытия;
- импорт принимает только безопасные растровые форматы фотографий;
- есть аварийный экран и диагностический отчёт без текстов рабочих записей.

## Новое в 2.5.0

- черновики всех основных форм автоматически сохраняются в отдельном внутреннем store и восстанавливаются после перезапуска;
- обновление предупреждает о несохранённых формах и рекомендует свежую резервную копию;
- настройки показывают дату последнего backup и занятое локальное хранилище;
- фото и импорт предварительно проверяются по доступной квоте, включая понятные сообщения о нехватке места;
- единая кнопка «Создать» открывает запись, задачу, осмотр или оборудование;
- добавлены задача из записи, повтор осмотра, копирование мероприятия и дублирование статьи;
- фильтры запоминаются, показывают активное количество и очищаются одной кнопкой;
- появились недавние объекты, избранное оборудование и статьи, восстановление последнего раздела;
- глобальный поиск охватывает журнал, задачи, осмотры, оборудование, мероприятия и базу знаний;
- оборудование ищется по IP, серийному номеру, обозначению и месту, мероприятия — по дате и ресурсам;
- компактный блок «Связано с» обеспечивает переходы без добавления отдельного графа связей;
- отчёты формируются за произвольный период, экспортируются в CSV, копируются и печатаются системным меню;
- готовность мероприятия показывает блокирующие причины, историю проверок, сравнение и имя проверившего;
- база знаний получила очередь перепроверки, перестановку шагов, дублирование и печатную версию;
- добавлены отмена изменения статуса через toast, предупреждение о дубликатах оборудования и режим повышенного контраста.

## Установка

1. Разместите содержимое этой папки в корне GitHub Pages.
2. Откройте опубликованный адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Откройте приложение с новой иконки при наличии интернета.
5. После загрузки проверьте запуск в авиарежиме.

## Обновление

При появлении новой версии приложение покажет панель «Доступна новая версия». Если есть черновик или давно не создавался backup, приложение покажет отдельное предупреждение и предложит сначала создать архив. Обновление применяется только после подтверждения.

## Резервная копия

Раздел: `Ещё → Настройки и данные → Резервная копия`.

- создаётся файл `БПС-Пульт-backup-YYYY-MM-DD.bpsbackup`;
- фотографии хранятся отдельными файлами внутри архива;
- перед импортом отображаются состав, предупреждения и совпадения;
- «Заменить» полностью заменяет базу одной транзакцией;
- «Объединить» сохраняет текущие настройки устройства и выбирает более новую версию совпавших записей.

Не удаляйте PWA и не очищайте данные Safari до создания проверенной резервной копии.

## Ограничения локального режима

- данные не синхронизируются между iPhone и ПК;
- удаление PWA или данных сайта способно удалить локальную базу;
- решение iOS о постоянном хранении остаётся системным;
- push-уведомления без серверной инфраструктуры не используются;
- окончательная проверка системной строки, safe-area и жизненного цикла установленной PWA выполняется на реальном iPhone.

## Иконка приложения

В проекте используются согласованные светлый и тёмный варианты иконки турникета с QR-билетом.

- `icon-192.png`, `icon-512.png`, `apple-touch-icon.png` — основной тёмный вариант для manifest/PWA;
- файлы с суффиксом `-dark` — тёмный вариант;
- файлы с суффиксом `-light` — светлый вариант;
- favicon и apple-touch-icon переключаются вместе с темой приложения.

У уже установленной PWA iOS может сохранять прежний значок. После публикации новой версии для гарантированной замены значка потребуется удалить только ярлык с экрана «Домой» и добавить приложение из Safari заново. Перед этим обязательно создать резервную копию данных.
