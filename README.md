# БПС Пульт v2.0.0 Alpha 3

Локальная mobile-first PWA для инженера билетно-пропускной системы. Данные хранятся только в IndexedDB на устройстве; сервер, аккаунт и интернет для ежедневной работы не требуются.

## Что добавлено в Alpha 3

### База знаний

- 12 стартовых предметных разделов;
- вложенные пользовательские разделы;
- типы материалов: инструкция, решение неисправности, регламент, справка, чек-лист и памятка;
- структурированная карточка: область применения, требования, шаги, ожидаемый результат, диагностика и заметки;
- полнотекстовый локальный поиск по названию, содержимому, шагам, тегам и пути раздела;
- фильтры по типу, актуальности и избранному;
- избранные и недавно открытые материалы;
- статусы актуальности и автоматическая пометка «Требует проверки» через 365 дней;
- подтверждение актуальности;
- история до 20 предыдущих версий и восстановление;
- связи с оборудованием и мероприятиями;
- включение базы знаний в резервную копию и полную очистку данных.

### Мероприятия Alpha

- гибкое включение БПС, СИБ, онлайн- и офлайн-продаж, печати, контроля прохода и резервного интернета;
- индивидуальные режимы гейтов и конкретных турникетов;
- кассы, несколько кассиров и смены;
- автоматический чек-лист только по выбранной конфигурации;
- расчёт готовности по важности проверок.

## Сетка и эргономика

Интерфейс основан на 4/8-point grid:

- боковой отступ страницы: 20 px;
- основной шаг: 8 px;
- внутренний отступ карточек: 16 px;
- расстояние между разделами: 32 px;
- поля: 48 px;
- минимальная зона касания: 44×44 px;
- строки списков: не менее 72 px;
- карточки: радиус 14 px;
- bottom sheet: радиус 20 px.

## Проверка

```bash
node tests/event-logic.test.js
node tests/knowledge-logic.test.js
```

Проведена браузерная проверка на viewport 390×844 и 320×700: отсутствие горизонтального скролла, фиксированная нижняя навигация, создание/изменение/поиск статьи, история версий и тёмная тема.

## Публикация

Загрузите содержимое этой папки в корень репозитория GitHub Pages. После публикации откройте сайт в Safari и перезапустите установленную PWA. Кэш версии: `bps-pult-v2.0.0-alpha.3`.
