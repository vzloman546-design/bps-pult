# БПС Пульт 2.0 — Alpha 1

Локальная mobile-first PWA для инженера билетно-пропускной системы. Версия `2.0.0-alpha.1` добавляет гибкую конфигурацию мероприятий поверх проверенной версии 1.3.

## Что реализовано

- создание мероприятия с нуля или из шаблона;
- режимы СИБ: не используется, полностью, частично, резерв;
- индивидуальный статус каждого гейта;
- выбор режима каждого турникета;
- рабочие, резервные, закрытые, незапрошенные и неисправные турникеты;
- любое количество назначений кассиров по сменам;
- автоматическая генерация чек-листа только по выбранным ресурсам;
- взвешенный процент готовности;
- критические проверки и блокирующие неисправности;
- сохранение результатов уже выполненных проверок при изменении конфигурации;
- копирование мероприятия;
- статусы: запланировано, подготовка, проводится, завершено;
- связь мероприятия с записью журнала, задачей и техосмотром;
- полная локальная работа в IndexedDB;
- экспорт и импорт мероприятий в общей JSON-копии;
- офлайн-кэш версии `bps-pult-v2.0.0-alpha.1`.

## Гибкая логика

Шаблон только создаёт начальную конфигурацию. После этого можно отдельно настроить системы, гейты, каждый турникет, кассы и смены кассиров. Неиспользуемые ресурсы не попадают в чек-лист и не снижают процент готовности.

## Проверки

```bash
node tests/event-logic.test.js
```

Проверяются девять сценариев, включая матчи с СИБ и без него, частичное использование гейта, резерв, закрытые гейты, кассовые продажи, сохранение статусов чек-листа и критическую неисправность.

UI проверен на ширинах 390, 375 и 320 px: горизонтального переполнения нет, нижняя навигация остаётся фиксированной, формы и карточки помещаются в viewport.

## Установка на iPhone

1. Разместить содержимое папки в корне GitHub Pages.
2. Открыть сайт в Safari.
3. Нажать «Поделиться» → «На экран Домой».
4. После первого запуска приложение работает без сети.

Все рабочие данные остаются на конкретном iPhone. Перед удалением PWA или очисткой Safari нужно сделать экспорт JSON.
