# БПС Пульт v1.2.1

Локальная mobile-first PWA для инженера билетно-пропускной системы.

## Как запустить локально на ПК

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.

## Как разместить бесплатно

Разместите содержимое этой папки на любом статическом HTTPS-хостинге: GitHub Pages, Cloudflare Pages, Netlify или Lovable. Серверная база не нужна.

## Установка на iPhone

1. Откройте опубликованный HTTPS-адрес в Safari.
2. Дождитесь полной загрузки приложения.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите приложение с иконки.
5. Включите авиарежим и убедитесь, что оно открывается.

## Хранение данных

Все данные находятся в IndexedDB браузера на конкретном устройстве. Приложение не отправляет их на сервер. Перед очисткой Safari, удалением веб-приложения или сменой iPhone создайте резервную копию в разделе «Ещё» → «Настройки и данные».

## Состав v1.2.1

- экран «Сегодня»;
- журнал событий с поиском и фильтрами;
- задачи и сроки;
- чек-листы технических осмотров;
- реестр оборудования;
- фотографии, сжимаемые на устройстве;
- итоги дня, копирование и системное меню «Поделиться»;
- экспорт и импорт полного JSON-архива;
- светлая, тёмная и системная тема;
- офлайн-режим через service worker.


## Жесты и анимации

- свайп вниз за верхнюю ручку закрывает карточки и формы;
- свайп влево по строке открывает быстрые действия;
- свайп от левого края возвращает из вложенных разделов;
- переходы и изменение элементов анимированы;
- системная настройка «Уменьшение движения» отключает лишние эффекты.

## Изменения v1.2.1

- более сдержанный интерфейс без крупных витринных карточек и повторяющихся быстрых действий;
- компактная сводка и рабочие списки в стиле системного приложения;
- нижняя навигация вынесена из трансформируемого контейнера и всегда закреплена у края экрана;
- тёмная стартовая область PWA и чёрный системный status bar для устранения белой полосы;
- сохранены свайпы, пружинные bottom sheets и офлайн-хранилище.

## Исправление 1.2.1

- строка состояния iPhone использует адаптивный режим `default`;
- светлая тема больше не получает принудительно чёрную системную область;
- `theme-color` и фон задаются до первого кадра;
- добавлены светлые базовые цвета и `color_scheme_dark` для тёмного режима;
- service worker обновлён до network-first, чтобы новые версии быстрее появлялись после публикации.
