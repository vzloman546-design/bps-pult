# БПС Пульт 2.0.0 Stable

Локальная mobile-first PWA для инженера билетно-пропускной системы. Приложение работает без серверной базы: рабочие данные хранятся в IndexedDB установленной PWA на конкретном iPhone.

## Основные модули

- гибкие мероприятия: СИБ, гейты, отдельные турникеты, кассы и смены кассиров;
- автоматически генерируемый чек-лист готовности;
- журнал событий и выполненных работ;
- задачи, сроки и приоритеты;
- технические осмотры;
- реестр оборудования;
- структурированная база знаний с разделами, поиском, историей версий и актуальностью;
- отчёт за день;
- офлайн-работа и установка на экран «Домой».

## Что делает версию Stable

- все операции IndexedDB подтверждаются только после завершения транзакции;
- восстановление резервной копии выполняется одной атомарной транзакцией;
- повреждённый архив не очищает текущую базу;
- поддерживаются миграции схем 1, 2 и 3 в схему 4;
- новый архив `.bpsbackup` является ZIP-контейнером с `manifest.json`, `data.json` и отдельными фотографиями;
- доступен режим «Заменить» и безопасное объединение;
- проверяются идентификаторы, даты и связи между объектами;
- удаления помещаются в локальную корзину на 7 дней и допускают немедленную отмену;
- при удалении мероприятия или оборудования связанные ссылки очищаются атомарно и восстанавливаются при отмене;
- добавлены контроль квоты и запрос постоянного хранения;
- обновление service worker применяется только после явного нажатия «Обновить»;
- модальные окна блокируют фон, удерживают фокус и возвращают его после закрытия;
- есть аварийный экран и диагностический отчёт без текстов рабочих записей.

## Установка

1. Разместите содержимое этой папки в корне GitHub Pages.
2. Откройте опубликованный адрес в Safari на iPhone.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Откройте приложение с новой иконки при наличии интернета.
5. После загрузки проверьте запуск в авиарежиме.

## Обновление

При появлении новой версии приложение покажет панель «Доступна новая версия». Обновление не применяется автоматически посреди редактирования. Закройте форму, нажмите «Обновить» и дождитесь перезапуска.

## Резервная копия

Раздел: `Ещё → Настройки и данные → Резервная копия`.

- создаётся файл `БПС-Пульт-backup-YYYY-MM-DD.bpsbackup`;
- фотографии хранятся отдельными файлами внутри архива;
- перед импортом отображаются состав, предупреждения и совпадения;
- «Заменить» полностью заменяет базу одной транзакцией;
- «Объединить» сохраняет текущие настройки устройства и выбирает более новую версию совпавших записей.

Не удаляйте PWA и не очищайте данные Safari до создания проверенной резервной копии.

## Ограничения локального режима

- данные не синхронизируются между iPhone и ПК;
- удаление PWA или данных сайта способно удалить локальную базу;
- решение iOS о постоянном хранении остаётся системным;
- push-уведомления без серверной инфраструктуры не используются;
- окончательная проверка системной строки, safe-area и жизненного цикла установленной PWA выполняется на реальном iPhone.
