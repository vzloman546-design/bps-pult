# БПС Пульт v1.3.0

Локальная mobile-first PWA для инженера билетно-пропускной системы. Все рабочие записи, задачи, осмотры, оборудование и фотографии сохраняются только в IndexedDB на конкретном устройстве.

## Главное в v1.3.0

- интерфейс полностью пересобран на единой 4/8-point сетке;
- боковые отступы шапки, страниц, карточек и bottom sheets унифицированы;
- минимальная интерактивная зона — 44×44 px;
- нижняя навигация постоянно закреплена у края экрана и учитывает Home Indicator;
- формы на iPhone используют один столбец, фильтры журнала — ровную сетку 2×2;
- списки, пустые состояния, карточки и заголовки имеют одинаковый вертикальный ритм;
- сохранены свайп вниз для закрытия, свайп влево по строкам и плавные анимации;
- светлая, тёмная и системная темы используют адаптивный `theme-color`;
- старые каскадные CSS-заплатки удалены, `styles.css` построен из одного набора токенов.

Подробный отчёт находится в [UI-AUDIT.md](UI-AUDIT.md).

## Установка на iPhone

1. Опубликуйте содержимое папки в корне GitHub Pages-репозитория.
2. Откройте опубликованный HTTPS-адрес именно в Safari.
3. Нажмите «Поделиться» → «На экран Домой» → «Добавить».
4. Запустите приложение с иконки один раз при наличии интернета.
5. Включите авиарежим и проверьте запуск.

## Обновление уже установленной PWA

1. Загрузите новые файлы поверх старых в ветку `main`.
2. Дождитесь завершения GitHub Pages deployment.
3. Откройте сайт в Safari и обновите страницу.
4. Полностью закройте установленное приложение и откройте его снова.

Service worker использует кэш `bps-pult-v1.3.0`, поэтому старая оболочка будет удалена при активации новой версии.

## Хранение данных

Приложение не использует backend, аккаунты, облачную БД или аналитику. Перед очисткой данных Safari, удалением PWA или сменой iPhone создайте JSON-резервную копию в разделе «Ещё» → «Настройки и данные».

## Локальный запуск на ПК

```bash
python -m http.server 8080
```

Откройте `http://localhost:8080`.
